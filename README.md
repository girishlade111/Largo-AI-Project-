# Largo AI Projects

A single-page marketing/landing site for **Largo AI** — "Innovation & Intelligence". Built as a plain static HTML page styled with Tailwind CSS (CDN), animated with Three.js, icons via Font Awesome, and Inter/Space Grotesk webfonts. No build step, no dependencies to install — open `index.html` in any browser.

## Features

- Hero landing section with smooth-scroll navigation
- Three.js animated visuals
- Responsive layout powered by Tailwind CSS
- Font Awesome iconography

## Tech Stack

- HTML5 + CSS3 + vanilla JavaScript
- Tailwind CSS (via CDN)
- Three.js (via CDN)
- Google Fonts (Inter, Space Grotesk)

## Quick Start

```bash
git clone https://github.com/girishlade111/Largo-AI-Project-.git
cd Largo-AI-Project-
# just open index.html in your browser, or:
npx serve .
```

## Project Structure

```
.
├── index.html   # the entire site — markup, styles (Tailwind CDN), scripts (Three.js)
└── README.md
```

## Deploy

The site is fully static. It is deployed on GitHub Pages (see homepage) directly from the `main` branch. Any static host (Cloudflare Pages, Netlify) works as well — just point it at the repo root.
